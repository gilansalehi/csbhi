# Archived drafting notes

The files in this directory preserve earlier stages of the Geometric Duality project. They are useful as a record of how the programme developed, but they are not authoritative statements of the current theory.

Use these sources instead:

1. `gd1.html` for the current paper and canonical notation;
2. `notes/gd_research_roadmap.md` for the current programme;
3. `notes/horizon_triple_identity.md` for the current status of the triple-identity hypothesis;
4. `notes/gd2_horizon_triple_identity_outline.md` for the GD2 construction target.

In particular, archived statements that treat a timelike matching shell as already constructed, identify that shell with the null event horizon, or use the same symbol \(r\) for Bob's coordinate and Alice's areal radius have been superseded.
